Keamanan & status

Gemini API key hanya disimpan di Supabase Edge Function Secrets, bukan di GitHub atau browser. Endpoint AI memerlukan sesi login Supabase. Tambahkan secret bernama GEMINI_API_KEY pada Supabase Dashboard → Edge Functions → Secrets. Jika belum ada, analisis AI akan gagal dengan aman dan fitur existing tetap berjalan.

Free tier Gemini memiliki batas penggunaan yang dapat berubah. Analisis otomatis hanya berjalan pada menu yang diaktifkan, bukan seluruh website.

Probabilitas adalah frekuensi transisi historis yang teramati pada data yang tersedia, bukan probabilitas terkalibrasi atau jaminan arah pasar. Gunakan sebagai konteks risiko, bukan sinyal beli/jual tunggal.

Metode: return equal-weighted lintas saham untuk setiap tanggal, lalu return kumulatif 20 sesi: Bull ≥ +3%, Bear ≤ −3%, selain itu Sideways. Matriks dihitung dari perpindahan state berurutan. Transisi dengan sampel nol ditampilkan sebagai 0%; state dengan sampel sedikit dapat menghasilkan estimasi tidak stabil.

Foreign Flow

Kolom foreign buy/sell tidak tersedia pada file screener historis yang digunakan halaman ini, sehingga net foreign flow tidak dihitung atau diestimasi.

Untuk data resmi harian, cek Ringkasan Saham BEI. Otomatisasi foreign flow memerlukan feed data yang memuat foreign buy dan foreign sell; fitur ini tidak mengklaim mengakses feed tersebut.

Sumber harga/volume: data/screener.json dari workflow repository. Data bersifat sesuai timestamp pembaruan file. Bila file gagal dimuat, pastikan GitHub Pages melayani file JSON tersebut. Analisis bersifat informasional.

AI Research Pack

Ekspor snapshot riset dari terminal SPC, lalu unggah file JSON ke ChatGPT untuk diperkaya dengan berita terbaru, keterbukaan informasi BEI, corporate action, dan konteks makro. Semua pengayaan eksternal dilakukan saat Anda meminta ChatGPT menelusuri web—terminal tidak memerlukan API key atau token AI.

1. Siapkan file untuk ChatGPT

Ambil data JSON yang tersedia dari terminal dan buat satu paket yang rapi. Klik tombol pertama untuk paket data, tombol kedua untuk prompt analisis yang bisa langsung disalin/diunggah.

Bandingkan dengan snapshot sebelumnya

Unggah file AI Research Pack (.json) dari minggu sebelumnya. File lama tidak dikirim ke server; perbandingan dibuat di browser dan disertakan ke paket ekspor terbaru.

Belum ada snapshot pembanding. Tanpa file sebelumnya, perubahan mingguan tidak akan disimpulkan.

2. Cara menggunakan

1
Buka halaman ini setelah pipeline data SPC selesai berjalan, lalu ekspor JSON.
2
Unggah JSON ke ChatGPT. Sertakan prompt analisis yang diunduh, atau salin instruksi dari file tersebut.
3
Minta ChatGPT melakukan web research terbaru dan mencantumkan sumber serta tanggal publikasi untuk setiap berita dan corporate action material.
4
Review ulang angka, tanggal cum/ex/record/payment, status aksi korporasi, dan sumber resmi sebelum report dipakai untuk keputusan investasi.

Data yang dibundel

  • Sinyal teknikal dan momentum
  • Market Intelligence dan status pasar bila tersedia
  • Sector Rotation
  • Value Gap dan Dividend Intelligence
  • Relative Strength, Early Signals, commodity play dan catalyst data bila tersedia
  • Metadata: waktu ekspor, status sumber, jumlah baris, serta file yang gagal dimuat
  • Equity Intelligence Graph: ekspor Intelligence Brief dan thesis JSON secara terpisah dari halaman Equity Intelligence Graph, lalu unggah bersama paket ini untuk stress test dan web research.

Hanya data yang tersedia di terminal yang disertakan. File kosong, stale, atau gagal dimuat akan ditandai—tidak diisi dengan angka rekaan. Paket ini tidak menyertakan kredensial atau token.

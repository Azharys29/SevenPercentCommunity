Aturan validasi dan fallback

  • Technical Score, sinyal, momentum, Value Gap, dan Dividend Intelligence internal SPC tetap menjadi sumber utama.
  • Data yang tidak tersedia, belum diperiksa, stale, invalid, atau dibatasi kuota tidak boleh diubah menjadi nol maupun sinyal bearish.
  • Price Agreement hanya dapat disebut cocok/berbeda jika kedua harga berasal dari tanggal dan basis penyesuaian yang dapat dibandingkan.
  • News Sentiment harus menyertakan waktu publikasi dan sumber; skor sentimen tidak otomatis menjadi rekomendasi beli/jual.
  • Macro Reference harus menyebut negara, indikator, unit, tanggal observasi, dan sumber. Indikator AS tidak dianggap sebagai data makro Indonesia.
  • API key hanya tersedia di GitHub Actions secret; key dan respons mentah tidak disimpan dalam JSON publik.
